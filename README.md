# DeliTracker

Aplicación Android en Kotlin y Jetpack Compose.

La autenticación usa Firebase. La configuración del proyecto real y el servidor de pruebas local se explican en [la documentación de Firebase](wiki/Firebase.md).

La configuración, alcance y demo de los avisos de restaurantes cercanos y ubicación de amigos se explican en [Notificaciones](wiki/Notificaciones.md).

Abrir esta carpeta en Android Studio. El proyecto incluye Gradle Wrapper 8.7.
